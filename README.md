## Mpemba effect without a wall (2026), Sane & Bechhoefer.

Raw files to generate figures, as well as .tex and .ipynb code to generate subfigures. Processed simulation data is included. All .ipynb code requires the [mpemba_langevin](https://github.com/Element200/mpemba_langevin) library, as well as the prerequisites defined there, to function.
